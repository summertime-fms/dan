# Портфолио — summertime-fms.github.io/dan

Статический сайт на Vite + TypeScript.

## Локально

```bash
npm install
npm run dev
```

Сборка: `npm run build` (базовый путь `/dan/` для GitHub Pages).

## Деплой

Пуш в `main` репозитория [summertime-fms/dan](https://github.com/summertime-fms/dan) — workflow **Deploy GitHub Pages** публикует на https://summertime-fms.github.io/dan/
