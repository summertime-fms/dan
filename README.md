# Личный сайт Михаила Данюшина

Fractional AI-инженер и оркестратор IT-процессов — одностраничный лендинг.

## Стек

- Next.js (App Router) + TypeScript
- Tailwind CSS 4
- Framer Motion

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Env

Скопируйте `.env.example` → `.env.local` и при необходимости задайте `NEXT_PUBLIC_CAL_URL` (ссылка Cal.com / TidyCal).

## Контент

Тексты и цифры — в `content/copy.ts` и `content/cases.ts` (источник: пакет брифов в корне репозитория). Не выдумывать факты сверх документов.
